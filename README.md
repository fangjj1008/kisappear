# 消失の写字板 · Kisappear

只露一条光标的写字板。**打进去的字不显示在屏幕上**，屏幕上始终只有一条闪烁的竖线。
打完 `Ctrl+A` → `Ctrl+C`，内容作为纯文本进剪贴板，粘贴到你要发出去的地方。

窗口 34×23 逻辑像素、无边框、置顶。单文件 `kisappear.exe`（约 100 KB），免安装，
只需要 Windows 自带的 .NET Framework 4。

## 什么时候用

开会/上课/值班时想打字，但不想让内容被人看见：屏幕上只有一条光标在动，
别人看不出你在写什么。写完再一次性复制走。

## 三步

| | |
| --- | --- |
| **1. 直接打字** | 字全部进 buffer，但画面不画字，只有光标在走；窗口宽度不变，光标左侧的字移出视野 |
| **2. 鼠标移到窗口上** | 向右展开，露出状态条（文件名/行:列）和三个按钮：取色、缩小、关闭 |
| **3. `Ctrl+A` → `Ctrl+C`** | 全选并复制，剪贴板里就是纯文本；贴到聊天框、邮件、任何输入框里 |

想留在本地就 `Ctrl+S` 存成 `.txt`。

## 操作

| 动作 | 结果 |
| --- | --- |
| 左键单击 | 放置光标，并取消全选 |
| 左键拖动 | 移动窗口（窗口太窄，挪位置比拖选常用） |
| Shift+左键拖动 | 拖选一段 |
| 右键单击 / 右键拖动 | 菜单（新建/打开/保存/取色/恢复默认色/置顶/最小化/退出）/ 移动窗口 |
| 中键滚轮 | 上下一行 |
| 点缩小 | 最小化到任务栏，内容保留 |
| 点关闭 | 有未保存内容时先问 |
| 取色按钮 | 把窗口颜色换成屏幕上任意一点的颜色（只影响本次运行，不写盘） |

快捷键：`Ctrl+C / V / X / Z / Y / A / S / Shift+S / O / N / W`、`Ctrl+←/→` 按词跳、
`Ctrl+Home/End` 到文首文末、`Shift+方向键` 扩选、`Esc` 取消选区。
中文直接打（微软拼音、搜狗等都可以），候选窗钉在光标处。

## 下载

到 [Releases](../../releases) 页下载 `kisappear.exe`，双击即可运行。

## 自己构建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1        # -> bin\kisappear.exe
powershell -ExecutionPolicy Bypass -File build.ps1 -Test  # 纯函数单元测试
```

只需要系统自带的 `csc.exe`（.NET Framework 4），不装任何 SDK。

## 说明

- 文字"消失"不是因为颜色透明，而是渲染层根本没有绘制文字的通道 —— 只读文本和插入点来画光标
- 输入由一个正常工作的编辑控件承担，所以撤销、剪贴板、输入法都是系统原生行为
